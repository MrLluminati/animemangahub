- Retained only the approved unified Shorts frame in Git.
- Preserved website and Shorts production as separate workstreams.

## External-service note

Jikan had returned repeated upstream `504` responses during the July 18 live-search retries. On July 19, the public Jikan v4 anime and top-anime endpoints again returned populated JSON responses. The complete AniManga Wire search interaction had already passed controlled service-boundary and native WebDriver validation; temporary upstream availability is therefore recorded as an external-service condition rather than an application regression.

## Known limitations

- A genuine vector or layered editable source for the current logo family is not available.
- Vercel and Railway deployment jobs remain intentionally disabled until hosting and production secrets are configured.
- Dedicated Arrow Up/Down active-suggestion highlighting remains an optional accessibility enhancement; native Tab, Shift+Tab, Enter, Space, Escape, and ordinary-button suggestion semantics are validated.

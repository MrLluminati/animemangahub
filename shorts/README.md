# AniManga Wire Shorts Workspace

This folder is for Shorts/Reels production assets, scripts, notes, and local output paths.

## Folder Roles

- `docs/` - production notes, style rules, and workflow documentation.
- `templates/` - reusable content/style templates.
- `scripts/` - local rendering and helper scripts.
- `outputs/` - local generated MP4 previews and samples. Ignored by Git except `.gitkeep`.
- `work/` - local intermediate renders, screenshots, and temporary files. Ignored by Git except `.gitkeep`.
- `exports/` - final local exports ready for upload. Ignored by Git except `.gitkeep`.
- `logs/` - local render logs. Ignored by Git except `.gitkeep`.
